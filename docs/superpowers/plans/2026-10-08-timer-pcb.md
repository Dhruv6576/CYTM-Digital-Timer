# CYTM Digital Timer PCB Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Generate a complete, DRC/ERC-clean KiCad 10 project (schematic, 2-layer PCB, Gerbers, BOM, renders, 3×2 film panel) for the 24 VDC cyclic timer, from one Python circuit description.

**Architecture:** One Python file (`circuit.py`) holds every part, net and placement. Generators turn it into a `.kicad_sch` (symbols + net labels) and a `.kicad_pcb` (pcbnew API, run with KiCad's bundled Python). Freerouting routes the board through Specctra DSN/SES. `kicad-cli` runs ERC, DRC with schematic parity, and all exports. Plain-assert test scripts check the netlist against the firmware pin map.

**Tech Stack:** KiCad 10.0.6 (`kicad-cli`, bundled Python + `pcbnew`), Freerouting (jar, Java 17), Python 3.10 (user install) + PyMuPDF for the film panel.

**Spec:** `docs/superpowers/specs/2026-10-07-timer-pcb-design.md`

## Global Constraints

- Board 50 × 80 mm, portrait, 4 × M3 (3.2 mm) holes, 4 mm from each corner.
- 2 copper layers, 1.6 mm FR-4, 1 oz copper.
- Front (F) side: display, 4 LEDs, 3 keys, screw terminal only. Everything else on back (B).
- Design rules (JLCPCB-safe): track ≥ 0.25 mm, clearance ≥ 0.2 mm, via 0.6/0.3 mm.
- Net classes: `Load` (VIN_RAW, OUT_P) track 3.0 mm; `Power` (VIN, +5V, GND) track 0.6 mm; `Default` 0.25 mm.
- MCU pin map exactly as the spec table; firmware `Final/5-26.c` must not change.
- ERC: 0 errors. DRC: 0 errors, 0 unconnected items, schematic parity clean.
- No git repo in this folder: no commit steps.

## Review Focus

1. Symbol pin names for MG51FB9AE (N76E003AT20 symbol) differ from the assumed pinout → wrong board. Task 1 test prints and asserts the 20 pin names.
2. Display segment/digit pins swapped → wrong characters. Task 2 test asserts SEG_A..SEG_DP land on display pins named A..DP and DIG1..3 on CA1..3.
3. Load traces thinner than 3 mm → overheating at 5 A. Task 5 test asserts every track on VIN_RAW / OUT_P is ≥ 3.0 mm.
4. Reversed input feeds the logic or coil directly → damage. Task 2 test asserts only D1 anode, K1 COM and J1 pin 1 sit on VIN_RAW.
5. Tall part on the panel side, or SMD on the front → does not fit / not like reference. Task 4 test asserts side of every footprint.

## File Structure

```
hardware/
  scripts/
    env.py          # paths to kicad-cli, KiCad python, libraries, freerouting jar
    sexpr.py        # tiny S-expression parser/printer (for .kicad_sym and .kicad_sch)
    circuit.py      # parts, nets, placement: single source of truth
    gen_sch.py      # circuit.py -> timer.kicad_sch
    gen_pcb.py      # circuit.py -> timer.kicad_pcb (run with KiCad python)
    route.py        # pre-route load nets, Freerouting, import SES, fill zones
    export.py       # gerbers zip, drill, bom, pdf, renders
    films.py        # 3x2 film panel PDF + PNG preview
  tests/
    test_libs.py     # symbols/footprints exist, MCU pin names
    test_circuit.py  # netlist rules + firmware pin map
    test_pcb.py      # sides, widths, outline
  timer.kicad_pro / .kicad_sch / .kicad_pcb
  output/
```
